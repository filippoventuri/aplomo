# Aplomo

Página de ejemplo para una constructora de casas que trabaja con precio cerrado por partidas, fecha de entrega en el contrato y pago por avance.

Ver en vivo: https://filippoventuri.github.io/aplomo/

- Un solo `index.html` con HTML, CSS y JavaScript sin dependencias, más la carpeta `assets/`.
- Al hacer scroll, el video muestra la casa construyéndose desde los cimientos hasta el atardecer. En celulares se usa un recorte más liviano del mismo video.
- El contacto es por WhatsApp. El número está en una sola línea del script (`WA_NUMBER`) y por ahora está vacío: el enlace abre WhatsApp con el mensaje listo y quien escribe elige el chat.
- El formulario es de demostración: muestra el mensaje de confirmación pero no envía datos.

Aplomo es una constructora ficticia. Las imágenes y el video fueron generados con IA.
